# CyberDesk

CyberDesk is a desktop application designed to display system information, perform basic security checks, provide a locally running AI assistant, and analyze your internet connection.

## Project Status

Currently in early development.

## Planned Features

- System information and monitoring
- Basic security checks
- Local AI assistant
- Internet connection analysis

## Technologies

- Python

## About

CyberDesk is a personal project created to improve my programming skills and explore software development, system administration, networking, and cybersecurity.
